## About me

I build software that removes routine work: robots that drive desktop apps such as 1C:Enterprise,
Telegram bots that report and alert, scrapers for internet-banking portals, and websites with Django and React.
Most of my automation projects run every day in a real retail & fintech company.

- 🏭 **Production experience.** My automation runs unattended every day: exports, reconciliations, reports and alerts that people used to do by hand.
- 👁️ **Computer vision in practice.** Recognising handwritten numbers in scanned court documents with OpenCV + OCR.
- 🌐 **Full stack.** From Windows UI automation and REST integrations to Django back ends and React front ends.
- 🎯 **Next goal.** Study Computer Science at a top university and grow from automation into software engineering and AI.
